# BUGFIX — Task Manager

## Возможные ошибки и улучшения

### 1. Пустая задача
Проблема: пользователь может попытаться добавить пустую задачу.

Решение: использовать strip() и проверять наличие текста.

### 2. Ошибка чтения JSON
Проблема: файл tasks.json может содержать некорректные данные.

Решение: обрабатывать JSONDecodeError.

### 3. Потеря задач после закрытия программы
Проблема: изменения могут не сохраниться.

Решение: сохранять задачи при добавлении, удалении и закрытии приложения.

## Возможные дальнейшие исправления

- Добавить резервное копирование JSON-файла.
- Улучшить обработку ошибок записи.
- Добавить проверку структуры JSON.
- Добавить автоматическое сохранение изменений.
